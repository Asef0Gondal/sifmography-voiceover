# 🎙 Sifmography Voiceover

A production-grade, high-volume TTS audio generation desktop application designed specifically for creators. Powered by `edge-tts`, it features intelligent character-mapping, dialogue sequence synthesis, custom voice preset layouts, and automatic chunking (3,000 words per canvas) to handle massive webtoon scripts natively with a robust macOS application interface.

---

## ✨ Features
- **⚡ edge-tts Power:** Zero-cost, high-speed cloud TTS engine with natural voice presets.
- **📁 Auto-Chunking:** Automatically slices massive scripts into 3,000-word sections to prevent API timeouts and throttle errors.
- **🛡 Smart Resume:** Flawless resume/interrupt safeguards for high-volume audio generation runs.
